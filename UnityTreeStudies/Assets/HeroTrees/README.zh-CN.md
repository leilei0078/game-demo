# Hero Trees · 新版四树研究

保留旧版 TreeStudies，新增雕叶云杉、密簇冷杉、疏冠老松、曲干古橡。当前为参考方向的游戏资产初版，尚未达到参考图的雕刻与树冠精细程度。

## 导入 Unity

将本目录完整复制到 Unity 项目的 Assets/HeroTrees，等待导入完成后执行 Tools > Hero Trees > Build Prefabs and Materials。工具会创建 Materials 与 Prefabs，每个预制体包含三级 LODGroup 和树干 CapsuleCollider。源 FBX 为米制、根部坐标为零。

Built-in 使用随包双面裁剪 Shader；URP 使用 Lit。当前新版未完成 Unity 实机导入验证，URP 也未实测。HDRP 需手动建立材质。不要将尚未生成的预制体视为已验证资产。

每个 LOD 两个网格、两个材质。共享 1024² 树皮、1024² 裁剪叶片图集、256² 实体叶片色板。近景云杉不适合在中端手机上大量使用最高 LOD。推荐 LOD 与实例化，只给近景投影。Alpha Clip 减少几何，仍有像素填充与阴影开销；尚无手机实测帧率。
