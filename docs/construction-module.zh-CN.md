# 建造模块 · 第一版

2026-11-16。状态：首版原型规则，数值和建筑选择为本轮实现假设，可在试玩后调整。

## 玩家流程

打开建造 → 选择物资堆场 → 预览、旋转、点击放置 → 空闲工人自动接单 → 从仓库领料送到工地 → 材料齐备后施工 → 完工开放新的卸货点。手动派工仍可指定人员。没人可派时，新蓝图等待工人空闲；已在其他任务中的工人不会被抢走。

复用运输采集模块的工人、载重、移动速度、排队、任务队列和受阻恢复。原型继续使用几何模型。首个建筑选择物资堆场，是为了让完工收益可以通过实际运货观察；住所、食物生产、灯塔的专属功能后续接入同一施工流程。

## 首版规则

| 项目 | 规则 |
| --- | --- |
| 物资堆场 | 占地3×2格，木材18件、矿石6件，施工24工人秒，最多2人同时工作；均为实验参数 |
| 放置 | 每格1米，90度旋转。检查边界、建筑/资源/工人、工作入口、初始待命点和练习主通道；红色预览说明具体原因。黄色入口/朝向提示；右键或Esc退出放置 |
| 缺料 | 可以先放蓝图；不提前扣资源，显示缺什么、多少已到、多少在途；有库存后已派工者自动继续 |
| 人员 | 同一批工人既能运料也能施工；玩家决定分配几人。两处工地工作位和仓库装卸位分别排队 |
| 施工站位 | 从工地周边可达候选点按实际路径选近侧，最多两人同时占用；最近侧被挡会寻找其他侧，缺料/满员在近侧等待。堆场黄色入口是完工装卸口，与施工站位分开 |
| 领料 | 领料动作完成时，按工地未到且未在途的需求、仓库现货和工人载重取最小值；一次只运一种材料。库存扣减与工人携货同时发生 |
| 建造顺序 | 左键选工地，可修改档位、上移、下移或置顶。全场未完工工地共用清单；跨档移动沿用目标档，同档按手动顺序，初始按放置先后。靠前可达工地先派空闲工人；只重排自动建造后续任务，不打断当前工作，不跨过手动指令 |
| 供料顺序 | 按同一清单为有人执行的靠前工地保留尚缺材料；已运出材料照常送达。暂停、无人或全部人员受阻不保留库存。排名不保证完工顺序 |
| 运到 | 搬到工地工作位、卸料完成后才记入已到材料；满料后开始累计施工劳动。只放蓝图、空等或暂停不涨进度 |
| 完成 | 完工只生效一次，开放2个装卸点，采集工人自动选可达且较近的点；建筑成本保留在已投入记录中 |
| 暂停工地 | 保留已到材料和进度；在途材料退回仓库后等待，人员仍保留该工地任务。恢复后继续；玩家也能改派 |
| 停止/改派工人 | 保留携货；解除原工地的在途分配。转做其他采集或工地前先将旧货入库；手动停止则待命携货 |
| 取消工地 | 施工前或施工中均可取消，已到材料在原址变成退料箱；在途材料留在工人身上，可送库。取消不生成已消耗之外的新材料，无劳动力退款 |
| 道路受阻 | 保留任务、材料与劳动进度，沿用自动重试及修路后恢复；正常排队与受阻分别显示 |
| 后续队列 | 支持追加建造指令，原采集本轮入库后交接；建造完成后交接后续任务 |

## 界面

建造按钮与放置预览；建筑清单按未完工、供料优先级排序，可直接选择工地；工地面板展示材料已到/在途/缺口、劳动进度、运输/施工/等待人数、具体缺料/在途/受阻/等待优先工地原因、暂停/继续、取消及派1/2名空闲工人。定位材料只移动镜头，不下令。首次建造七步引导贯通采集、施工和保存。工人状态覆盖领料、运料、卸料、等待材料和施工。采集统计新增建造劳动与相关耗时，建材领出和退回不算新增采集收益。

## 数据与边界

每类资源遵守：世界初始数量 = 所有资源点/退料箱剩余 + 工人携货 + 仓库库存 + 所有未取消建筑已投入材料。在途数量是携货的分配标记，不额外加入总量。完工的材料仍记作建筑投入，取消则把该投入转成退料箱。

现有仓库采用全局共享库存；新堆场是额外装卸入口，尚不模拟各仓库存和跨仓调拨。未实现拆除已完工建筑、升级、维修、地形高差、独立职业或迷雾范围限制。优先级影响派工和供料，不提高劳动速度。施工、优先级及排位、建材在途与退料均可手动保存恢复；详见 `local-save.zh-CN.md`。

## 验收

1. 从原有资源实际采集、入库，再运料施工，完工后实际通过新堆场入库。
2. 空库存蓝图不扣料、不空涨进度；补料后继续；多人领料不超领。
3. 无效摆放不创建工地、不扣资源；旋转后的占地与工作位一致。
4. 暂停/继续、停止/改派、取消以及封路恢复，逐帧检查数量守恒与在途分配。
5. 完工功能只生效一次；新的建造活动不破坏旧采集流程和统计含义。

验证结果与操作入口在完成后写入项目进度记录。
