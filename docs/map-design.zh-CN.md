# 01.3 地图设计（2026.11 起）

**已确认：** 地图采用正方形网格，每格在地图平面上的长和宽相等。

**尺度方向：** 按放置对象使用不同大小的方格：铺马路用小格，摆建筑用大格。建筑大格是摆放时的对齐单位，不表示每栋建筑都只能占一格。

**建议，未定案：** 大小格共用原点和方向，大格边长是小格边长的整数倍。例如，一个建筑大格可覆盖 2×2 个道路小格，路能沿建筑边缘铺，也能对准入口。这样不必为每种设施各建一套互不对齐的网格。

**待定：** 小格的实际边长、大格与小格的比例，以及是否需要其他尺度。现有基础路面的 1 米边长仅作参考。放置网格不限定工人只能沿格线或逐格移动。

## 试玩：把路铺到堆场门口

1. 建造 → 仓储物流 → 放置蓝图。鼠标附近显示建筑大格，堆场中心按大格移动；轮廓才是实际占地（3×2 米）。按 R 看入口转向，两个黄色小框是装卸口对应的道路格。
2. 放下堆场后，选建造 → 基础设施 → 铺设基础路面。工具改用小格，靠近堆场会重新标出同一对入口格。左键点一格或拖直线到黄框，松开确认。蓝图阶段即可规划接路，不必等完工。
3. 退出放置时隐藏网格。路可以铺到装卸口，不能压入建筑本体；先铺路再摆堆场也遵循同一规则。不接路仍可施工和装卸，围墙不享受路面的通行规则。

本版试用 **1 米小格、2 米大格**，大格边界与小格边界重合。数值供试玩，不是最终地图规格。旧档中的堆场保留原坐标，不强制移到新格心。

默认从地图对角线方向俯看，俯角 30°，使用正交投影。从屏幕上看，一个方格呈宽高约 2:1 的菱形；从地图上量，它仍然是正方形。拖铺沿菱形的两组边走，堆场的青色轮廓表示实际占地，不代表单个方格。

## 地表：荒地

开局是一整片灰褐色荒地，以裸土为主，压低土色变化和砂砾的对比，不铺草地、不预画道路。自然地表不按格切块，让建造网格和玩家铺的道路有清楚的边界。第一版只换平地材质，保留现有资源点、高度、碰撞与通行规则。
